# Contraste visual del P3020

La paleta oficial usa azul `0 0 0.15` en veinte elementos, que aparece casi
negro en RViz. Se añadió `steel_preview`, una variante visual aproximada de
azul acero más claro, conservando los dos elementos blancos. Se utiliza solo
en las vistas provisionales con gripper; el modelo oficial por defecto y las
colisiones permanecen intactos. No se agregaron logotipos ni luces inexistentes.
El paquete compiló y pasaron 11 pruebas; se reinició la vista del P3020.
